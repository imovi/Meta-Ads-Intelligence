# Creative Analysis

Use this reference when the user asks to analyze an ad image, video, Reel, copy, hook, CTA, or creative test.

## Creative framework

Break the creative into:

1. Hook
2. Problem/pain
3. Solution/product
4. Benefits
5. Proof
6. Offer
7. Objection handling
8. CTA

Then assess:

- clarity
- relevance
- differentiation
- visual hierarchy
- message-to-market fit
- credibility
- friction
- urgency

## Hook analysis

Assess whether the first message creates a reason to continue.

Useful hook categories include:

- problem
- curiosity
- benefit
- transformation
- demonstration
- social proof
- objection
- offer
- comparison
- contrarian angle

Do not assume a hook is effective merely because it sounds strong. Connect it to actual CTR, hold rate, watch time, or conversion data when available.

## Image analysis

Inspect:

- product prominence
- first-glance message
- text readability
- contrast
- composition
- brand recognition
- offer visibility
- CTA clarity
- social proof
- visual clutter

## Video/Reels analysis

When the source permits, inspect:

- first 1–3 seconds
- opening visual
- pacing
- scene changes
- subtitles/text overlays
- voiceover
- product demonstration
- proof
- objection handling
- offer reveal
- final CTA

Do not invent details that cannot be seen or heard.

## Copy analysis

Evaluate:

- first sentence
- clarity of value proposition
- specificity
- benefit orientation
- proof
- objections
- offer
- CTA

Separate what the copy says from whether performance data proves it works.

## Creative testing

When comparing creatives, use the user's primary business KPI first and supporting metrics second.

Example:

```text
Primary KPI: CPA
Secondary: conversion rate, CTR, CPC
Context: spend, conversion volume, date range
```

A creative with a better CTR is not necessarily the winner if downstream conversion economics are worse.

## New creative generation

When asked to create new concepts:

1. Identify what worked.
2. Identify what failed.
3. Extract reusable principles.
4. Generate multiple distinct angles.
5. Avoid cloning competitor wording or design.
6. Give each concept a clear hypothesis.

Recommended output:

```text
Concept:
Angle:
Hook:
Visual:
Primary text:
Headline:
CTA:
Hypothesis:
What to test:
```
