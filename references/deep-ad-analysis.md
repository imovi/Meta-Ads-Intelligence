# Deep Ad Analysis

Use this module for a single Facebook/Instagram ad, creative, Reel, image, or video.

## Analysis layers

### 1. Creative

Inspect when visible:

- format
- first 1–3 seconds
- hook
- visual hierarchy
- product visibility
- text overlay
- pacing
- demonstration
- proof/social proof
- CTA

### 2. Copy

Evaluate:

- hook
- problem/pain point
- desire/outcome
- benefit
- objections
- proof
- offer
- urgency/scarcity when genuinely present
- CTA

### 3. Message match

Compare ad promise with the visible landing-page or destination message when available.

Check whether:

- the same core promise continues
- the offer is consistent
- the CTA is consistent
- important claims are supported

### 4. Performance

Use available metrics such as:

- impressions
- reach
- frequency
- CTR
- CPC
- CPM
- conversions
- CVR when calculable
- CPA
- revenue
- ROAS

Compare against a meaningful baseline when available. Do not label a metric "good" or "bad" without a target, benchmark, or sufficient context.

### 5. Psychology

Describe observable persuasion mechanisms rather than claiming certainty about user psychology. Possible mechanisms include:

- problem agitation
- benefit framing
- demonstration
- social proof
- authority
- risk reduction
- curiosity
- urgency
- identity/status

### 6. Diagnosis

Separate:

- **Observed** — directly visible or measured
- **Inferred** — reasonable interpretation
- **Unknown** — not supported by available evidence

Never infer private targeting, private spend, or conversion causes from creative appearance alone.

## Output

Use this structure:

1. Ad summary
2. Performance snapshot
3. Hook analysis
4. Creative analysis
5. Copy analysis
6. Offer and CTA
7. Message/landing-page match
8. What appears to be working
9. What may be limiting performance
10. Recommended tests
11. Confidence and missing data

## Test recommendations

Prefer isolated variables:

- new hook, same body
- new opening visual, same copy
- new proof, same offer
- new CTA, same creative

Do not claim a test will win; frame it as a hypothesis.
