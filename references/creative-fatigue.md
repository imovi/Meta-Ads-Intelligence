# Creative Fatigue Intelligence

Use this module to detect possible creative fatigue from comparable historical periods.

## Signals

Look for multiple signals together:

- CTR declining
- CPA increasing
- frequency increasing
- conversion volume/rate declining

A single weak metric is not enough to declare fatigue.

## Minimum evidence

Prefer at least three comparable periods. Compare like-for-like date ranges where possible.

Consider:

- spend
- conversion volume
- audience size
- placement mix
- delivery changes
- seasonality
- offer changes
- tracking/attribution changes

## Example interpretation

> CTR declined 24%, CPA increased 31%, and frequency increased 28% across the comparable period. This is a likely fatigue signal, but audience saturation and delivery changes should be checked before attributing causality to creative fatigue.

## Response strategy

If fatigue is likely:

1. Keep the proven core message where useful.
2. Change the opening hook or visual substantially.
3. Test a fresh format or angle.
4. Preserve the control when possible.
5. Define a success metric before launching the test.
6. Compare after sufficient spend/conversion volume.

## Do not

- kill a creative solely because frequency is high
- call a creative fatigued from one day's CTR
- assume fatigue when tracking broke
- automatically pause the creative

The module produces a recommendation; execution requires the explicit Action workflow.
