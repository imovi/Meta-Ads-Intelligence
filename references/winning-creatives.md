# Winning Creative Detection

Use this module to identify repeatable creative patterns from ads with sufficient performance evidence.

## Winner definition

A creative should not be called a winner from ROAS alone.

Consider:

- spend
- conversion volume
- ROAS
- CPA
- CTR
- conversion rate
- stability across comparable periods
- creative fatigue

Tiny samples must be flagged.

## Pattern analysis

Group ads by observable attributes such as:

- hook type
- angle
- format
- offer
- CTA
- proof type
- visual style when consistently coded

For each pattern calculate aggregate metrics from totals where appropriate.

## Repeatability

A single top ad is an individual winner.

A pattern appearing across multiple sufficiently funded ads is stronger evidence of a repeatable pattern.

Example:

> Three UGC ads using a problem-led hook generated stronger aggregate ROAS than other sufficiently funded creative groups.

This is an observed association, not proof that UGC or the hook caused the result.

### Why it may work

Use creative analysis to propose hypotheses based on observable differences.

### What to test next

Generate controlled variations that isolate one variable at a time.

## Avoid

Do not claim:

- a creative is profitable because it is visually attractive
- a competitor's creative is a winner without performance evidence
- one metric proves causality
- a pattern will continue indefinitely
