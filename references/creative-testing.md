# Creative Testing & Generation

Use this module after winner detection and fatigue analysis to create controlled creative hypotheses.

## Testing principle

Change one primary variable at a time where practical.

Possible variables:

- hook
- opening visual
- proof
- offer framing
- CTA
- angle
- format

Keep the strongest validated elements as controls when possible.

## Test matrix

Every proposed test should include:

- test ID
- control
- changed variable
- concept
- retained variables
- hypothesis
- success metric
- minimum evidence/decision rule
- stop condition

## Creative generation

Generate original variations inspired by observed patterns. Do not copy competitor creative verbatim or imitate protected branding, testimonials, or identity.

### Hook directions

Useful directions include:

- problem-first
- outcome-first
- curiosity
- demonstration
- proof-first
- objection handling
- comparison when truthful and substantiated

## Success metrics

Select the primary metric based on the business objective:

- CTR for attention/traffic tests
- CPC for click efficiency
- conversion rate for landing/offer tests
- CPA for acquisition efficiency
- ROAS for revenue efficiency

Avoid optimizing a creative test solely on CTR when the actual objective is profitable conversion.

## Sample size

Do not declare a winner from tiny samples. Define a minimum spend/conversion threshold before launch and use comparable attribution settings.

## Fatigue-aware generation

If fatigue is detected, favor a materially different opening hook, visual treatment, angle, or format rather than making only cosmetic edits.

## Action boundary

Generation creates a test plan. It does not automatically publish ads, change budgets, or pause controls.
