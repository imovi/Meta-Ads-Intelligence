# Monitoring & Alerts

Monitoring compares comparable periods and surfaces material changes for investigation.

## Core metrics

- ROAS
- CPA
- CTR
- spend
- conversions
- frequency
- creative fatigue signals

## Alert philosophy

Alert thresholds are configurable decision-support rules, not universal benchmarks.

A useful alert states:

1. what changed
2. by how much
3. comparison period
4. severity
5. what should be checked next

## Diagnosis

Do not infer causality from one metric. A ROAS drop should trigger checks for conversion volume, spend, CPA, tracking, attribution, audience/delivery, placements, creative fatigue, offer, and landing-page changes where available.

## False positives

Suppress or downgrade alerts when:

- sample size is tiny
- attribution data is incomplete
- date ranges are not comparable
- tracking recently changed
- campaign was intentionally edited
- delivery is still stabilizing

## Action boundary

Alerts are read-only. No automated account changes are implied.
